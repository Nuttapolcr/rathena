# AGENTS.md

**All workflow rules live in [`CLAUDE.md`](CLAUDE.md). Read that file before
starting any work.** This file is a portable mirror of the entry point for
agent tools that look for `AGENTS.md`.

The three mandatory rules, in brief:

1. **Read before you work.** Scan [`docs/knowledge/README.md`](docs/knowledge/README.md)
   and [`docs/knowledge/INDEX.md`](docs/knowledge/INDEX.md); read notes
   relevant to your task before writing code.
2. **Record what you learn.** Found something non-obvious (had to read
   source / experiment / trace)? Write `docs/knowledge/<slug>.md` and add a
   row to `INDEX.md`, per the format in `docs/knowledge/README.md`.
3. **New system → write a README + log it.** A new subsystem ships its own
   `README.md` and gets an entry in [`SPECS.md`](SPECS.md).

See [`CLAUDE.md`](CLAUDE.md) for the full text, the doc map, and build/test
instructions.
